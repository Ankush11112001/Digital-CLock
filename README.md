# ⏰ Digital Clock

This is a simple **real-time digital clock** project built using HTML, CSS, and JavaScript. It displays the current time on a webpage and updates every second.

## 🔧 Features

- Real-time clock display
- Auto-updates every second
- Uses JavaScript `Date` and `setInterval` methods
- Clean and minimal design

## 🛠️ Technologies Used

- **HTML** – Structure of the page
- **CSS** – Styling the clock
- **JavaScript** – Real-time clock logic
